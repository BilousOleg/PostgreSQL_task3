# 1 Зв'язки між таблицями

## Створити базу даних та таблиці для бронювання номерів у готелі. Продумати типи даних та обмеження для полів. Реалізувати зв'язки між таблицями. Заповнити таблиці тестовими даними.

Короткий опис предметної області:
Система описує роботу готелю.
У базі даних зберігається інформація про клієнтів (ім’я, прізвище, дата народження), номери (номер кімнати, тип, вартість за добу) та бронювання.
Кожен клієнт може бронювати кілька номерів, а кожен номер може бути заброньований різними клієнтами у різний час (зв’язок «багато-до-багатьох», реалізується через таблицю Bookings).
Таблиця бронювань містить інформацію про дату початку та завершення проживання, а також оцінку, яку клієнт може залишити після проживання (спочатку NULL, після завершення — заповнюється).

## Реалізувати такі запити (звертайте увагу на те, що потрібно вивести):

Відобразити імена та прізвища клієнтів та номери кімнат, які вони бронювали.

- Створити представлення по запиту 1.

- Відобразити оцінку клієнта Івана Іваненка для номера 101.

- Відобразити клієнтів, які мають оцінку нижче 3.5.

- Відобразити клієнтів, які бронювали номер 101 та залишили оцінку.

- Відобразити середню оцінку та кількість бронювань для кожного клієнта.

- Відобразити клієнтів, які мають середню оцінку вище 4.0.

- Відобразити номери, які ще жодного разу не були заброньовані.

- Отримати список клієнтів, у яких день народження збігається із днем народження Івана Іваненка.

- Відобразити клієнтів, які мають середню оцінку вищу, ніж Іван Іваненко.

- Отримати список номерів, у яких вартість за добу більша, ніж у номера 101.

- Отримати список клієнт | номер | оцінка, де оцінка має бути більшою за будь-яку оцінку Івана Іваненка.

- Вивести клієнт | номер | оцінка, щоб оцінка виводилася у вигляді "відмінно", "добре" або "задовільно".
